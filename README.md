# Worst AI Advice: The 48-Hour Tight Line Open

One line of the worst advice an AI could give, in its confident, tidy assistant voice: reuse "password" as your password everywhere, so you'll never forget it — and neither will anyone else. Specific, followable, instantly regrettable, and it lands without explanation.

## Run it

```sh
python3 main.py
```

Writes one line (107 characters, UTF-8) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `/output/entry.txt` if that variable is unset. Python 3 standard library only, no network, deterministic.
